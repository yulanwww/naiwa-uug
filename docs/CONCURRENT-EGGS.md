# 连续臭鸡蛋与并发音效

## 实现
- App 以 Map 保存每颗独立 action，React key 使用稳定 ID；数组渲染多个 EggEffect。每颗保持原飞行/破裂/飞溅素材、真实落点和 1120ms 生命周期，单独完成后移除。
- 只监听角色展示区域的 primary pointerdown，不同时监听 click/touchstart，避免一次触摸双计数。
- 命中回调按 action.impacted 去重，只有实际成功命中才累计。每三次命中创建独立、有唯一 ID 的待扣分票据，绑定投掷开始时的头像 ID。
- 一轮活动鸡蛋全部结束后进入 recovering；PetSprite 的真实站立完成信号到达后，按序消耗队列。每笔独立随机扣分、写入持久化、追加红色浮动数字并播放扣分音效。数字列表避免同批多笔被 React 批处理覆盖。
- 恢复期间仍可接收新投掷，新投掷取消旧恢复票据但保留扣分队列，等待下一次有效恢复信号。旧回调匹配失败不会结算。
- 每次撞击以 Web Animations 重新开始同样的轻微受击反馈；头像和身体同在角色 Canvas 中移动。站稳检查同时等待动画和肚皮弹簧停止。
- 头像切换、重置、模式退出在当前动画和结算结束前锁定，避免错误归属；下一轮拍肚子控制器保持原逻辑。

## 音频
- 蛋壳与扣分各自共享已解码 buffer 和 gain=0.5，每次播放创建短生命周期 BufferSource，允许自然重叠，播放新声音不停止旧声音。
- onended 断开并删除音源；卸载停止剩余音源并关闭 context。每路最多 48 个活动音源。
- 加分音效明确保留此前单音源模式；冰冰冰、大笑及其音量、速度和时序未改。

## 极端输入边界
- 最多同时 24 颗活动鸡蛋；普通快速连点无需等待前一颗结束。
- 一轮无间断投掷最多接受 48 颗，达到后仅暂停接受新投掷，已有鸡蛋继续演完并在站稳后结算，再恢复输入，防止无限输入永远挤占结算节点。
- 被保护上限拒绝的极端输入不生成 action，也不累计命中或扣分。既有鸡蛋不被丢弃。

## 测试
- verify-concurrent-eggs.mjs：隔离 Edge 390×844 触摸模拟；3/6/9 颗并发、不同落点、分别扣分 1/2/3 次、只在站稳后写入、音效并发无截断、结束清理、头像归属、重置、双跳与加分。
- verify-egg-burst-limit.mjs：极端输入峰值 24 颗；持续输入仍在结束前结算；成功观察 96 次命中，准确结算 32 次，分值 −19392（测试固定随机选择606），无超额扣分。
- verify-egg-audio-unit.mjs：重叠音源、自然结束释放、音源上限、音量、加分单音源及异常/卸载处理。
- 未进行实体 iPhone/Android 性能或实际扬声器试听；浏览器测试验证播放启动及音源生命周期。
