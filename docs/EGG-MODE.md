# 臭鸡蛋素材与模式

- 原图：用户提供的 `腐坏鸡蛋冲击特效素材表.png`。仅采用前两行的鸡蛋、破裂、蛋液阶段，没有臭气、眩晕或底部装饰。
- 使用内置 imagegen 进行背景移除、透明抠图和阶段整理；保留生成的 alpha。透明底并非普通矩形裁切。半透明液体来自有色背景，不能保证逐像素恢复原始无背景光学透射颜色。
- `public/effects/egg-stages.png` 是透明图集，`egg-00.png` 至 `egg-07.png` 为独立透明阶段，manifest.json 记录阶段顺序。Canvas 使用图集与各阶段命中中心坐标绘制。
- 抠图提示：仅提取前两行八个完整蛋、裂蛋、破裂、飞溅阶段，保持蛋壳纹理和湿润蛋液，四列两行排列，透明背景，无第三四行元素。第二次针对背景移除，要求所有渐变底色 alpha 为零，保留液滴空隙和柔和边缘。
- 飞行 420ms，撞击开裂及飞溅 700ms，共 1120ms。单 RAF 驱动；素材未加载时等待真实纹理，加载失败显示错误并解除锁定，不计命中。
- 点击模式按钮仅切换模式；蛋模式仅 `.pet-platform` 的 primary pointerdown 投掷。client 坐标通过实时 bounding rect 转为 192×208 逻辑空间，不受页面滚动影响。
- 飞行期间锁定互动和模式切换。一次命中回调有组件及 App 双重去重。计分沿用原头像 ID 和原有每三次命中结算，未改随机规则。
- 模式切换丢弃未完成的拍肚子连击，不启动声音。已有音频播放时序与双跳控制器保留。
- `scripts/verify-egg-mode.mjs` 使用独立 Edge 测试环境，覆盖模式、触摸落点、滚动、透明度、重复点击、三次扣分、头像独立持久化、原有双跳及音效。
- 未进行真实 iPhone 或 Android 设备测试。桌面 Edge 的移动视口和触摸模拟不等同于实体手机。
