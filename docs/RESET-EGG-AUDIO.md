# 单头像好感度重置与鸡蛋碎裂音效

## 重置
- 复用 localStorage 的 affectionByAvatarId；reset(id) 仅将该 ID 写为 0n，其他键不变。
- 当前头像数值旁提供小按钮；复用原生 dialog 抽屉，支持取消、关闭、Escape、遮罩关闭。
- 打开时以 ref 锁定 ID 和名称；确认同步消耗票据，防止重复执行。弹窗阻止切换头像及开始互动。
- 拍击计数、等待音效、大笑、鸡蛋飞行/撞击阶段均禁用重置。结算完成并回到 idle 后才能重置。
- 原头像图片及 IndexedDB 数据不迁移、不清空。重置不清除其他头像分数或投掷进度。

## 音效
- 用户提供的原始 MP3 复制到 public/audio/egg-crack.mp3，SHA256 与附件一致：7049A8A0454826835B9B5FADE8D48A1F25C0CE216690E2752C5F860601ADBE30。
- 浏览器解码时长约 1.0202 秒；原文件内容、速度和音调未变。
- 单个 Web Audio context，单个 gain=0.5，至多一个活动 buffer source。每次新命中先停止旧 source，再播放一次。
- 挂载预取、解码；真实投掷 pointerdown 中 resume；音效仅由带去重票据的 eggImpact 触发，不依赖另设延时。
- 加载/解码/播放失败均不阻塞动画和计分。未解码就绪或浏览器不允许播放时，该次音效可能无法播放，不在稍后补播过时撞击。
- 原有冰冰冰、大笑音量与播放顺序未变。

## 验证
- verify-reset-egg-audio.mjs：隔离 Edge 390×844 触摸模拟，覆盖取消/关闭/Escape、四类头像单独重置、正负分、刷新、互动锁定、重置后加减分、命中音效及失败降级。
- verify-egg-audio-unit.mjs：验证单 source 替换停止、不重叠、gain 0.5、失败与卸载清理。
- 不等同于真实手机实测；未实际听音评估硬件输出延迟。
