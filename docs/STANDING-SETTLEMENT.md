- 大笑完成回调和鸡蛋特效完成回调均进入 recovering 阶段，期间锁定拍击、投掷、模式切换、头像切换和重置。
- PetSprite 已绘制正常 idle 姿势，肚皮弹簧清零，且 CSS 受击动画不再运行，连续两个渲染帧满足条件后发送一次 onStable(recoveryId)。不使用额外延迟计时器猜测恢复时间。
- 统一 standing 回调先消耗当前票据，然后按互动开始时绑定的头像 ID 执行一次结算。卸载取消渲染循环并清除待结算票据。

- 解码/播放失败不阻塞结算；浏览器拒绝播放或素材未准备好时，该次提示音可能缺失，不延后补播。

- 浏览器自动化验证播放启动与动画信号；未进行实体 iPhone/Android 或实际听音的硬件延迟测试。
