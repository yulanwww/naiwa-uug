# Naiwa 本地修复记录：无旋转换脸与果冻肚皮

## 无旋转换脸
- image.js：移除 crop.rotate、照片 rotate 和非等比例绘制；固定圆形柔边遮罩。
- FaceEditor.jsx：删除照片、整体脸部和逐帧角度控件；图片仅按 source 解码一次，
  位置变化直接重新绘制。Pointer Capture + 相对增量实现不限制范围的四向拖动；
  保持 touch-action:none，添加仅归零 x/y 的「重置位置」。
- model.js：旧数据归一化，仅保留有效位移/等比缩放参数，不应用旧角度。
- storage.js：旧数据库版本不变、不删除数据；读取时在内存中重建无旋转缩略图，
  不重写原记录，保存编辑结果时不再写入裁剪/位置/锚点角度。
- anchors.js：删除帧角度，输出 w=h 的统一比例。
- PetSprite.jsx：取消头部遮罩和照片的旋转，照片一直保持上传时的方向。
- styles.css：拖动区域禁止文本选择，以棋盘格显示透明区域。
原来存在的具体问题是 ±1.5 的位置硬限位与每次移动重新解码照片。
这两处都已移除；本机测试验证现在可向上/下/左/右拖动，越过原边界。
没有使用 react-easy-crop。EXIF 由浏览器正常解析，不再额外改角度。
保存、预览、缩略图使用同一个 renderPatch，不再发生额外自动裁剪。
照片最终仍受奶蛙头部安全遮罩限制；超出黄色头部边缘的部分会被裁切，不会拉伸补齐。

## 果冻肚皮：实际图像网格变形
原先的变形范围在奶油色肚皮内部归零、位移很小，因此没有推动奶油色边界，
主要可见的是径向阴影。现已删除肚皮所有阴影/径向渐变绘制。
Canvas 2D 用 26×26 顶点、25×25 单元的三角纹理网格重绘原图：
- 变形范围扩展至肚皮边界之外的一小圈原版黄色躯干。
- 位移场带动实际奶油色边界，向头部、手臂、脚部平滑衰减为零。
- F=-340x-11.5v，冲量驱动，固定小步长积分。
- 点击位置决定局部压缩中心，传播项也只移动原图像素，不绘制任何波纹。
- 允许动量叠加，限制最大位移以防翻转；每帧从原始精灵帧重新采样。
- 三角覆盖处理抗锯齿接缝；头部和四肢保护区恢复原始像素。
- 大笑启动时结束肚皮弹簧，保留原版跳跃大笑，避免捧肚手臂被额外拉扯。

实测中心拍击时，奶油色区域中心线下沿由约 y=137 收至 y=126，
回弹越过原位至 y=141.5，随后多次衰减，约 1.2 秒回到原图。
这是色彩阈值跟踪的边界坐标，单位为原图像素，不是阴影大小。
原图没有深度/法线或独立肚皮层，因此是有弹簧物理的二维纹理形变，
不是三维表面压入；不会生成新的侧面几何。奶油色肚皮轮廓确实改变，
整只角色没有缩放，头部与四肢保护区像素差为零。

## 验证
真实 Edge 无头浏览器，390×844 CSS px，鼠标与 CDP 单指触摸模拟：
- 鼠标/触摸四向拖动、越界拖动、透明空白、位置与缩放互不重置通过。
- 正向与横向测试图不旋转；EXIF=6 JPEG 方向正常解码。
- 11 个动画帧无角度变换、无照片宽高比变化，只有位置和等比尺寸变化。
- 旧头像保留源照片、名称、位移与缩放，保存/切换/刷新正常。
- 裁剪预览中心像素与保存缩略图一致。
- 肚皮真实轮廓凹陷、过冲、回稳、不同点击中心、连续冲量通过。
- 全部 60 个检查帧的肚皮内部未检测到 alpha<250 的纹理接缝。
- 拍击肚皮外部不触发，触摸三连拍大笑通过。
- 原版待机、大笑、头像增删改查、刷新持久化通过。
- 原版精灵图 Git blob 哈希未变。
- 网格绘制本机测量平均约 2.5 ms，峰值约 9 ms；不是实体手机性能保证。
- npm.cmd run build 通过。

测试使用隔离浏览器配置和几何图像，不会清空或污染用户当前浏览器头像库。
未在实体手机测试，也没有真实用户人像的拟真效果评估。
