## 动作来源与时序
pet.json 只声明 spriteVersionNumber=2，没有动作时序。
对原始 spritesheet 第 4 行 5 帧目视核对：
0 蹲身准备起跳；1 上升腾空；2 最高点；3 下降；4 落地。
两端都是接近同一基线的落地/蹲身姿态，原序列已含完整跳跃。
没有增加 CSS 跳跃、角色缩放或额外整体位移。

每帧 300ms；第 0–1500ms 播放 0,1,2,3,4，
第 1500–3000ms 再播放 0,1,2,3,4。到 3000ms 在下一次画面刷新恢复待机。
低分辨率原素材仅有 5 帧，保留原帧的阶梯式姿态变化，不伪造中间帧。

## 修改文件
src/pet/animations.js：
1500ms 周期、2 轮、3000ms 总时长，frameAt 计算当前周期的原始帧。
durationOf 为播放器提供整个动作的完成阈值，不再第一轮结束就回待机。

src/App.jsx：
使用统一 motion {animation,playbackId,startedAt} 状态。
进入大笑入口时同步锁住重复输入，清空原连击计数，记录同一开始时间并请求音频播放。
只在动作入口调用一次新音频；第二轮没有独立音频回调或定时器。
大笑完成才释放锁，下一轮拍击仍按原逻辑播放冰冰冰。
大笑音频与冰冰冰各有一个持续 audio 元素，预加载，不按点击创建实例。
卸载暂停两个音频；恢复待机不暂停大笑音频，保留约 0.18 秒尾音。

src/features/audio/laughSound.js：
进入大笑时先暂停冰冰冰，再用同一个 laugh 元素从零播放。
第二次跳跃不重播。新的大笑动作复用该元素，不叠加多个大笑实例。
音频异常被捕获，不阻断动画，音频播放由用户拍击或按钮点击同步发起。

src/components/PetSprite.jsx：
用 motion.startedAt 驱动 requestAnimationFrame 的统一 elapsed。
3 秒后仅完成一次；两轮连续绘制同一 Canvas，不卸载/重载精灵或照片。
照片每帧使用既有位置锚点，仍不旋转、不非等比拉伸。
大笑状态继续禁用拍肚和额外肚皮形变。
