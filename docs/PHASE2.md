# 第二阶段实现说明

## 检查与备份
修改前已经把 src、public、index.html、package.json、package-lock.json、README.md
复制到 backups/phase1-20261023-165603，未覆盖第一阶段文件。
实际检查到的初始代码只有待机与大笑按钮，没有拍肚或三连拍实现。
因此保留原动画定义，补接了 1.2 秒内三次肚皮有效拍击触发大笑的入口。
直接点击奶蛙肚皮和「拍肚子」按钮共享同一个计数逻辑。
点击头部/肢体不会计数；大笑过程中不会重新触发大笑。

## 肚皮
使用 Canvas 2D 的 18×18 双三角纹理网格，局部位移场边界归零。
每次拍击在肚皮椭圆内记录归一化位置，弹簧参数 k=420、阻尼=13。
负位移产生凹陷，欠阻尼产生向外过冲与衰减；近位置拍击累积速度，
不同位置保留最多 8 个局部弹簧。小时间步积分，避免低帧率时发散。
边缘归零、受限遮罩与局部明暗提示共同表现形变。不是缩放整只奶蛙。
大笑时使用更小的下腹安全区，尽量避开捧肚的手。
限制：原素材无独立腹部纹理、法线、深度或四肢图层。
因此是二维纹理的局部位移和深浅反馈，不是真实三维压入；不能产生新的侧面几何或遮挡。
待机定格像素对比：肚皮有变化，头部/四肢保护区变化为 0。

## 换脸与锚点
保留原始精灵图，不修改 WebP。
照片先缩至最长边不超过 1600 px，保留一份可编辑的浏览器处理副本。
裁剪照片支持平移、缩放、旋转，生成柔边透明椭圆照片图层。
原版脸部边缘用当前原帧取样的黄色柔边底层抑制眼睛/嘴巴残影。
照片通过头部区域裁剪与原帧 alpha 内缩遮罩，保持黄色外轮廓，避免照片溢到背景。
每帧使用 anchors.js 的独立位置、宽高与角度；待机 6 帧，大笑 5 帧。
人脸与身体在同一个 Canvas 同一时间步绘制，切换帧时同步更新；没有固定 HTML 图片覆盖。
原版大笑帧本身有明显跳跃与体型变化，人脸同步跟随这些原始变化。
逐帧锚点调整和整体偏移会随每个头像一同保存；调整超出头部安全区时会被裁切。
照片表情保持静态，不会自动张嘴/眨眼，也不会做透视重建、肤色智能匹配或去背景。
建议使用正面、光照均匀的人像并手动把眼鼻嘴放入裁剪框。不同照片需要不同裁剪。
未提供真实用户照片，因此验证使用几何测试肖像，不声称已验证任意照片的拟真效果。

## 头像库
IndexedDB 数据库名为 naiwa-faces，版本 1。
faces 存头像数据，settings 存当前选择。保存操作等待事务完成才更新 UI。
保存头像名称、source、crop、placement、anchors、thumbnail 和 updatedAt。
支持多个头像、切换、编辑、确认删除和恢复原版，刷新可恢复头像库与当前选择。
数据只隔离到浏览器配置文件/源，不是按自然人识别；同一浏览器地址内会共享同一库。
无照片上传请求、无服务器持久化、无账号和云同步。
删除和保存错误有提示；清除浏览器网站数据会清空头像。

## 布局
390×844 CSS px 为基础，单列，宽度不超过 440 px。
奶蛙占主要视觉区域，肚皮可直接触摸，底部保留五个功能入口。
头像编辑器和头像库使用原生 dialog 底部抽屉，支持页面内滚动、关闭与 Esc。
使用 Pointer Events 处理裁剪拖动和拍击；未实现专门的平板或桌面布局。
